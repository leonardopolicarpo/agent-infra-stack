# v0.2.0 — Short-term Memory

## O que mudou

O agente agora persiste estado entre steps. Se o worker cair no meio de uma
execução, a task retoma de onde parou no próximo retry, sem reprocessar
nós já concluídos.

## Detalhes

**LangGraph PostgresSaver** — cada step do grafo gera um checkpoint no Postgres
identificado pelo `task_id`. O agente sobrevive a crashes do worker.

**Fluxo de checkpoint:**
```text
router → salva checkpoint
research → salva checkpoint
critique → salva checkpoint   ← se cair aqui, retoma do output
output → salva checkpoint final
```

**`task_id` como `thread_id`** — identificação única por execução,
isolamento total entre tasks diferentes.

## Stack

- `langgraph-checkpoint-postgres` v3.1.0
- `psycopg[binary]` v3.3.3
